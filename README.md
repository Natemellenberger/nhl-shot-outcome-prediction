# NHL Shot Outcome Prediction

This project uses NHL shot-level data from the 2025-2026 season to predict whether a shot results in a goal or is saved.

## Research Question

Can the characteristics of an NHL shot predict whether the shot will result in a goal or be saved?

## Models

- Logistic Regression
- Decision Tree Classifier

## Dataset

Shot-level NHL data from MoneyPuck.

## Key Features

- Shot distance
- Shot angle
- Shot type
- Period
- Player position
- Rebound status
- Rush status

## Project Files

- `nhl_shot_prediction.ipynb` — full analysis and machine-learning workflow
- `Data/shots_2025.csv` — 2025-2026 NHL shot data
